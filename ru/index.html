ABD — платформа быстрой разработки учётных приложений. Конфигурация — это дерево текстовых файлов на Lua-DSL: его удобно читать, хранить в Git и писать вместе с ИИ.

Как устроена конфигурация

Конфигурация — папка с текстовыми файлами. У каждого вида файлов своя роль.

.aform

Класс и форма в одном файле

Описание данных и экранная форма для них находятся рядом, в одном файле.

.lua

Поведение формы

Логика формы пишется на Lua в отдельном файле.

роботы

Проведение документов

Роботы выполняют проведение документов.

пример кода — короткий файл .aform и парный .lua, которые можно показать на главной.

Конфигурации лежат в отдельных публичных репозиториях. Примеры конфигураций готовятся, среди них — бухгалтерия, вырастающая в АБС банка.
