# abd.pro

Сайт платформы ABD. Статические страницы без сборки: что лежит в репозитории, то и публикуется через GitHub Pages.

## Структура

- `index.html` — перенаправление на русскую версию `/ru/`.
- `ru/` — страницы на русском: главная, `quickstart/` (быстрый старт), `download/` (загрузки).
- `assets/site.css` — оформление; цвета и шрифты задаются в блоке `:root`.
- `assets/downloads.js` — список сборок на странице загрузок. Имя репозитория с релизами вписывается в `RELEASES_REPO`.
- `CNAME` — домен `abd.pro` для GitHub Pages.

Английская версия добавляется папкой `en/` с теми же страницами.

## Пометки «уточнить»

Места, где текста пока нет, отмечены на страницах жёлтым блоком с классом `todo`. Найти все: `grep -rn 'class="todo"' ru/`. Перед запуском сайта их остаться не должно.

## Просмотр на своём компьютере

```
python3 -m http.server 8000
```

После этого сайт открывается по адресу http://localhost:8000/.
