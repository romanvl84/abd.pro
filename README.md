# abd.pro

Сайт платформы ABD. Статические страницы без сборки: что лежит в репозитории, то и публикуется через GitHub Pages.

## Структура

- `index.html` — перенаправление на русскую версию `/ru/`.
- `ru/` — страницы на русском: главная, `quickstart/` (быстрый старт), `download/` (загрузки).
- `assets/site.css` — оформление; цвета и шрифты задаются в блоке `:root`.
- `assets/downloads.js` — страница загрузок: берёт файлы последнего релиза этого репозитория и предлагает сборку под систему и процессор посетителя.
- `CNAME` — домен `abd.pro` для GitHub Pages.

Английская версия добавляется папкой `en/` с теми же страницами.

## Как выкладывать сборки

Сборки выкладываются как релиз этого репозитория (Releases → Draft a new release), файлы прикладываются к релизу. Страница загрузок показывает последний релиз, не помеченный как pre-release.

Страница распознаёт файл по словам в его имени, порядок и разделители не важны:

- продукт: `server` — сервер; иначе `abd` — инструмент автора;
- система: `windows` (или `win64`), `macos` (или `darwin`), `linux`;
- процессор: `x64` (или `amd64`, `x86_64`), `arm64` (или `aarch64`).

Пример: `abd-1.0.0-linux-x64.tar.gz`, `abd-server-1.0.0-windows-arm64.zip`. Файлы контрольных сумм (`.sha256`, `checksums.txt`) видны только в списке «Все файлы».

## Пометки «уточнить»

Места, где текста пока нет, отмечены на страницах жёлтым блоком с классом `todo`. Найти все: `grep -rn 'class="todo"' ru/`. Перед запуском сайта их остаться не должно.

## Просмотр на своём компьютере

```
python3 -m http.server 8000
```

После этого сайт открывается по адресу http://localhost:8000/.
